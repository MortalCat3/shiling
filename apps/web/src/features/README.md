# 业务功能

业务页面按功能组织，请求统一经 `app/http-client.ts` 访问 `/api/v1`。

- `identity`：初始化、登录、一次性邀请/恢复、再次确认身份与账号设置。
- `assets`：团队/公开素材库、筛选和分页、详情、文件授权预览与公开快照。
- `ingestion`：批次、文件核对、传输进度、取消/重试、元数据与服务端处理状态。
- `library`：标签字典、团队集合；收藏与归档复用素材库的查询视图。
- `administration`：成员、角色、产品设置、运行状态、任务与必要审计。

页面以服务端 `actions` 为资源操作依据，后端承担最终授权。结果未知的写操作先读取状态；PATCH 携带 `If-Match`，动作请求按合同携带修订号和幂等键。不得用占位数据掩盖接口缺失或把前端状态当作入库事实。
