# 原创界面演示素材

这些素材仅用于开发环境 `/demo/` 的视觉和交互验收，不代表真实团队内容、授权图库或用户作品。

- `study-01.svg`～`study-24.svg`：为拾灵编写的原创几何构成，覆盖不同配色和横、竖、方比例；没有外部图片或第三方字体。
- 同名 PNG：由相邻 SVG 使用项目已声明的 Sharp 0.35.5 渲染。PNG 中嵌入了来源描述；`manifest.json` 记录实际尺寸和字节数。
- `form-study.mp4`：从 `study-04.png` 制作的 4 秒、720×540、无音轨合成视频。使用 FFmpeg 编码，轻微缩放用于验证按需播放；`video.json` 记录元数据。

原始 SVG 是可编辑源文件。重新渲染后应重新写入来源元数据，并更新 manifest 的字节数。开发应用只消费 PNG/MP4，不在浏览器中引入 Sharp、FFmpeg 或媒体服务包。生产构建通过 `import.meta.env.DEV` 移除整个演示入口、接口和素材引用。
