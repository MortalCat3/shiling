# API 文档

[API 合同](../design/03-api-contracts.md)记录首期请求、响应、权限、错误、幂等与文件交付约定。身份、上传、素材、整理、公开、设置、任务和审计路由已经在 `apps/api` 注册；运行入口、配置和当前验证范围见 [API 服务说明](../../apps/api/README.md)。

设计合同仍包含尚未完整验收或尚未开放的分支，不能把“文档中存在路由”当作实现证据。当前正式边界如下：

- API 前缀为 `/api/v1`，团队端、公开端使用独立 DTO。
- 迁移由显式 CLI 完成，API/worker 启动不自动创建 schema 或队列。
- 当前存储驱动仅为 Local；S3 合同尚未实现和验证。
- 动效结构检查已实现，但不可信执行隔离未具备，新动效处理会安全失败。
- 已通过与未执行的真实结果统一记录在[首期部署与验收记录](../operations/deployment-validation.md)。
