# 原型落地与首期体验验收

- 日期：2026-11-16
- 方向状态：v0.2 已获用户确认，见 [ADR 0003](../adr/0003-prototype-visual-direction.md)。
- 本文状态：结合原型补充的实施与验收约定已随 P00 采用；全部用例尚未执行。
- 当前边界：M0 只更新合同并执行隔离技术 spike，不实现页面、业务接口或数据库。任务编号见[首期业务开发计划](../plans/phase-1-implementation.md)。

## 1. 共同视觉基准

默认拾灵外观沿用 v0.2：白色背景、灰黑文字、浅灰导航选中和筛选、紫色上传/管理动作、现有折页品牌方向。桌面素材图以原比例瀑布流呈现，卡片默认只有封面与小标题；必要类型/播放提示与操作浮层不挤占素材。格式、大小、标签和公开状态主要在详情、整理列表展示。

基准色、侧栏和顶栏比例、图片与详情圆角见[原型说明](../prototypes/v0.2/README.md)。采用统一设计变量与通用组件，不按每张生成图的细微差异建立多套样式。不增加欢迎横幅、统计卡片、绿色主题或新的品牌图形。

列表、排序、筛选与批量整理仍属首期；原型未画出不等于取消。新增入口保持紧凑，进入选择状态后显示批量操作栏，避免让默认浏览页堆满管理控件。具体断点、间距、文案与入口位置由工程实现和可用性走查收口，通常不需用户逐项审批；改变导航、主流程或业务范围时才提交取舍。

品牌名、Logo、主色按配置映射到团队与公开页面。后续实际复用品牌资源时检查来源；本原型图不能代替可分发的品牌源文件。

## 5. 验收方法与证据

1. 使用可再分发的合成样例和固定数据状态，记录版本、角色、公开状态、媒体类型、存储、浏览器与视口。静态 PNG 不能代替实际页面截图。
2. 建议布局检查样本为 1440 × 1024、1280 × 800、768 × 1024、390 × 844，并抽查窄屏与宽屏。它们是工程检查样本，不是要求用户提供的运行规模或最终断点。目标浏览器与必须支持的媒体能力由 D03 收口；未覆盖浏览器不能写为已支持。
3. 四个核心页面保留桌面截图，核心旅程至少保留一组手机截图或录屏；上传状态、详情返回与公开确认保留交互证据。按样本叠加键盘、触屏、减少动态效果和放大检查，不机械穷举所有组合。
4. 将实现截图与 v0.2 对照。以页面层级、图片密度、导航、配色、预览比例和动作位置为重点，不要求合成素材逐像素一致；偏离方向的修改记录原因，方向性变更再评审。
5. API 权限、公开字段白名单、并发与文件摘要用实际集成验收；UI 隐藏按钮和截图不能证明安全边界通过。没有后端结果的静态页面不算业务完成。
6. 验收记录标明通过、失败、未执行或不适用。M1 覆盖图片流程，M2 加入整理/视频/公开，M3 补齐动效与管理，M4 汇总全部范围；早期阶段不将尚未实现的用例记为通过。

核心操作不可完成、身份或内部信息泄漏、原件交付错误、虚假就绪、焦点无法退出弹窗、移动端关键操作被遮挡，均阻断对应任务验收。普通视觉差异作为问题记录按严重性处理，不以生成位图的细节误差增加无意义测试。
