# B「创作工作台」第一批验收

后续正式页面与真实服务端联调见[三批真实 API 验收](real-api-workbench-validation.md)。下文保留首批前端实现时的历史边界。

日期：2026-11-17。范围按 [ADR 0005](../adr/0005-interface-redesign-scope.md) 执行。当前记录只覆盖第一批前端，不替代已有业务和部署验收。

## 已实现范围

- 共用颜色、间距、圆角、按钮忙碌态与分段选择；侧栏采用团队范围，类型筛选保留在素材库工具条。
- 素材库网格/缩略图列表、搜索、类型/标签/集合/本人筛选、排序、收藏和持续批量结果。切换视图保持查询与选择，失败项保留名称和 revision。
- 桌面双栏详情、手机全屏详情、原件下载主动作、按需视频、元数据编辑与焦点恢复。公开设置保留既有权限逻辑。
- 上传批次导航、传输/处理/可用/失败状态、重试入口、取消记录；必要登录与会话失效反馈。

集合完整页面、公开页面和管理页面属于后续批次。此次没有修改数据库、API、worker 或真实上传策略。

## 运行与演示边界

按[开发指南](../contributing/development.md)使用仓库固定 Node/pnpm 启动 Web。正常入口 `/app/library` 继续使用真实 API。

开发服务器另有 `/demo/app/library`，页面顶部明确标记演示模式。24 份原创合成图和一段合成 MP4 的[来源](../../apps/web/src/demo/assets/README.md)可追溯。演示动作仅写当前页面内存，刷新即重置；不向正式 API 回退，不保存真实账号或团队素材。演示接口不支持的动作明确失败。生产构建不包含演示接口、图片、视频或场景切换器。

独立审阅初次要求修复手机多批次上传横向溢出与搜索占位文字对比度。修正后 390px 页面宽度仍为 390px，点击第三批次不会带动整页横移；占位文字对实际底色的对比度为 4.6957:1。复核把这两项均评为 `resolved`，最终 `disposition: ship` 仅覆盖该修复清单。B 没有独立 QUALITY BAR 图卡或批准效果图，因此评审依据是用户确认的 code-first 方向合同，不是图像复刻一致性。

## 限制

此次没有执行真实服务器上传、下载和 worker 全链路，也没有重跑数据库集成、部署与恢复演练。真实设备 Safari/Android、完整键盘矩阵、中文 IME、200% 放大、性能规模和断网恢复仍待专项验收。演示状态和合成媒体通过不能证明这些行为已在真实部署中通过。

设计组件约定见 [Web DESIGN](../../apps/web/DESIGN.md)；业务接口仍以详细设计和正式代码为准。
