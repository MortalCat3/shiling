## 实测结果

- `pnpm check:isolated` 退出码 0：工程约束、格式、lint、构建、类型、冒烟、存储合同 7 项、API 3 项、前端 9 项、数据库集成 8 项均通过，无跳过。
- 官方 SDK 通过本地协议服务完成 3 路并发、每路超过 9 MiB 的分片传输、SHA-256、跨分片边界 Range、覆盖拒绝与 GC 标记检查。
- 正式 API/worker 复用 12 组工作台业务回归：账号、角色/权限、图片/MP4、品牌 PNG/JPEG/WebP、集合、公开与撤回、Range、账号恢复和管理记录。
- 6 组恢复断言通过：10 个台账对象、合计 30,073 字节合成素材从数据库 dump 和对象备份恢复到新前缀，图片/视频全部产物、品牌、集合和元数据摘要一致；恢复到备份点之前的业务状态。
- 损坏备份、同源目标、配置归属错误均被拒绝；模拟恢复传输中断后公开保持关闭且数据库未重绑定。旧会话、邀请、恢复令牌、未到期 grant、待处理任务失效；新 worker 可完成上传，公开重开不复活已撤回内容，管理员代发仍被拒绝，所有者重新公开后游客可下载。
- Compose 合并配置验证通过：API/worker 挂载 OSS secret 并接入出网网络，preview 无存储凭据且只在内部网络，动效执行固定 false；原有数据库及认证 secret 没有被覆盖丢失。
- 独立本地 `shiling-runtime:oss-validation` 镜像构建成功；无网络、非 root、只读容器中验证 Local 写读/摘要、OSS 驱动/SDK 加载及缺失凭据拒绝。仅为临时验证镜像，不是发布版本，未推送。镜像的云网络、真实 OSS 连通性与容器级云端闭环尚未执行。
- 候选源码与文档使用 Gitleaks 8.30.1 扫描：358 个文件、约 2.16 MB，0 泄露；不扫描或复制被忽略的私密运行文件。工作区 diff 空白检查通过。

本地协议服务只模拟测试需要的 OSS HTTP 行为，不模拟阿里云服务本身。它能发现 SDK 接线和业务衔接错误，无法证明 RAM 策略、Bucket 配置或真实网络兼容。后续真实云结果须在取得授权输入并实际执行后记录。

配置、RAM 示例、Docker 出网范围、临时空间预算和成套恢复顺序见[OSS 运维说明](oss-storage.md)。
