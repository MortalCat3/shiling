## 接口边界

- 集合：GET/POST /team/collections；GET/PATCH /team/collections/:id；GET /items；POST /items:batch、/archive、/restore。
- 集合修改使用 If-Match 或 expectedRevision；条目操作是整体事务，不套用素材逐项结果格式。
- 标签：GET/POST /team/tags；PATCH /team/tags/:id；POST /enable、/disable；版本冲突保留草稿。
- 公开：GET /public/assets、/facets、/:id；POST /:id/delivery-grants。游客使用独立 PublicAsset 投影，无成员、集合或内部文件名字段。
- 快照：GET /team/assets/:id/publication；POST /publish、/withdraw。提交同时携带素材修订、公开修订、版本及明确填写的公开元数据。

新增组件边界：CollectionCover 只加载可见素材预览；CollectionEditor 管理集合元信息；CollectionActions 执行集合状态操作；CollectionAssetPicker 管理独立的跨页选择；PublicationForm 管理快照草稿和二次核对。样式增量在 organization.css，沿用已有语义变量。

环境：仓库固定 Node 24.22.3、pnpm 12.21.0；本地 Vite 与浏览器开发演示。尺寸包含 1440×900、1280×800、390×844；手机为浏览器视口模拟。

| 整批加入      | 选择两份素材提交，集合显示 2 项；再加入一项时模拟 412，整批未加入且选择保留，核对修订后成功显示 3 项                                      |
