## 发现与修复

1. **管理列表随机排序**：原任务/审计按 UUID 排序，最新操作可能落在后续页。现按 `created_at DESC, id DESC`；游标绑定时间、ID、访问范围和筛选。保留 PostgreSQL 微秒，不经 Date 截断，不依赖 DateStyle。旧游标需刷新。
2. **主动退出误报过期**：清空身份后受保护布局重新挂载，迟到的 401 覆盖成功退出跳转。现无身份时不挂载受保护页面，显式退出后忽略迟到的过期通知。浏览器已验证退出全部会话及普通退出均到 `/login`，无错误 expired 提示。
3. **账号菜单未收起**：选择账号/公开页或路由变化时关闭菜单，包含点击当前账号页的情况。
4. 补齐真实设置、品牌、成员状态、公开快照、任务重试审计动作的中文名称；未知动作保留标识。

本轮没有改动权限定义、数据库迁移、视觉 token、字体或公开资格规则。

工程检查另发现设计工具自动生成的 `hook.cache.json` 含机器路径，已精确加入 Git/格式检查忽略及源码检查排除；其他设计文档与评审证据仍照常检查，不跳过产品源码或设计问题。
