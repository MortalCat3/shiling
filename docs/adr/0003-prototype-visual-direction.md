# ADR 0003：沿用现有拾灵视觉方向

> 后续状态：固定沿用 v0.2、不再重选视觉的限制已由 [ADR 0005](0005-interface-redesign-scope.md) 替代。本文保留历史依据；新方向待确认，既有业务与详情交互仍作为评审基线。

- 日期：2026-11-16
- 状态：用户已确认视觉方向；业务实现与浏览器验收尚未开始
- 依据：用户确认“这版风格可以，后续就按这个方向”，并明确要求暂不开始业务开发
- 关联：[原型 v0.2](../prototypes/v0.2/README.md)、[首期业务开发计划](../plans/phase-1-implementation.md)、[原型落地与体验验收](../design/05-prototype-acceptance.md)

## 决定

1. 以 v0.2 的团队素材库、本人详情、上传工作区和公开素材页为后续视觉基准，不再重选整套视觉方向。
2. 延续现有拾灵的紫色折页品牌、白底灰黑文字、浅灰搜索与胶囊筛选、简洁线条图标、图片优先的原比例瀑布流。紫色主要用于上传和管理动作；不采用 v0.1 的绿色主题和四叶标识。
3. 桌面从素材库打开详情采用居中双栏弹窗；直接访问同一详情地址呈现独立页面，移动端使用全屏详情。深链、返回恢复列表、权限和文件交付规则不变。
4. 上传采用批次工作区，公开采用精简游客页面。保留新版流程，不恢复旧分类树、私人收藏夹、旧上传发布向导或历史数据兼容。
5. 名称、Logo 与品牌变量仍可由部署者配置；视觉方向确认不表示必须将当前团队品牌硬编码到通用核心。

## 确认范围

本次确认的是风格与主要页面布局，不是逐像素尺寸、所有未绘制页面、每个交互细节、示例素材或生产参数。字体、断点、列表与批量操作、错误状态和键盘操作由后续设计与实现按本方向补齐，接受可判定的实际验收。

原型中的素材、文件大小和数量均为示例。图片原件处理采用用户先前授权自行评估后的方案，依据与剩余资源输入见计划 P02、D03/D04；不是由视觉确认推导出该规则。

延续品牌视觉不等于取得旧 Logo、字体或其他资源的开源再分发许可。仅在实际引入或打包拟复用资源时核对来源与许可；不复制旧业务代码、真实素材或内部信息。

## 实施边界

本 ADR 当时只允许更新设计和任务文档，不授权业务开发。首期计划后来已由 [ADR 0004](0004-product-defaults-recovery-and-m0-scope.md) 确认，当前仍只授权 M0，完成后先汇报，不进入 M1。

v0.1 作为探索历史保留；v0.2 作为已认可方向保留。生成图不作为已实现功能或响应式验收证据，实际验收结果必须另行记录。
