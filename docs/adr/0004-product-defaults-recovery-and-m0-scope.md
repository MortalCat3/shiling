# ADR 0004：产品默认、灾备恢复与 M0 授权

- 状态：已确认；恢复安全 CLI 已实现，目标环境演练待完成
- 日期：2026-11-16
- 适用范围：首期产品合同、新系统自身备份恢复、当前 M0 工作边界

## 背景

首期计划、验收标准、产品默认和新系统自身的灾备恢复策略已经完成评审。此前文档把 P00、P01、P03 保留为待确认，会导致实施入口、恢复行为和验收口径不一致，需要在进入业务开发前冻结。

## 决策

### P00：计划与验收

采用 M0～M4、T00～T13 的任务顺序和 PF、ID、AU、UP、PB、FL、CF、EN、UX 验收体系。当前只授权 M0 的设计收口与隔离技术验证；M0 完成后先汇报，未获明确授权不得进入 M1。

### P01：首期产品默认

- 采用邀请制本地账号；固定不可编辑的 `sysadmin` 系统角色，首期每人绑定一个角色。
- 媒体必需产物合格后进入团队素材库；对游客公开是素材所有者的单独明确操作。
- 内部标题和说明采用纯文本；不接受任意 HTML。
- 采用团队集合与个人收藏；集合可归档/恢复，收藏只属于本人。
- 首期逐项公开；任何角色均没有代替他人公开、更新公开快照或重新公开的能力。
- 归档素材必须先恢复，才能重新下载原件、播放视频或主动执行动效；恢复不自动公开。
- 相同内容可以建立不同的逻辑素材；首期不进行跨用户全局物理去重。
- 上传者在入库前失去账号或上传资格时，该未完成项受控失败；资格恢复后必须手动重试，不自动复活。

图片工程基线沿用 P02：保留保真原件，取消旧系统固定 80,000 字节发布门槛，预览产物使用独立像素、内存和输出体积预算。具体支持格式与限额仍依据代表性样例和部署规模冻结。

### P03：新系统备份恢复后的安全姿态

从较早备份恢复新系统时，默认采取保守恢复：

1. 公开入口保持关闭，先完成数据、对象、成员、角色与配置核对。
2. 恢复出的会话、一次性邀请/恢复令牌、下载/预览授权和旧 worker 执行代次全部失效。
3. 恢复出的 `active` Publication 转为 `withdrawn`，保留不可变快照和历史修订，不删除素材。
4. 核对成员与角色后，由当前素材所有者逐项重新公开；管理员不能代发。
5. 已签发的第三方对象地址仍受其自身有限 TTL 约束；已下载副本无法远程收回。

P03 只适用于新系统从较早备份恢复，不改变 D01 的日常公开开关规则：正常关闭后再次开启，可以恢复仍然有效且从未撤回的既有 active 快照，但旧授权不会复活。

## 影响

- P00、P01、P03 不再作为待确认事项；P03 恢复安全动作已有 CLI 和专用数据库测试，完整备份恢复与目标环境运行验收仍未完成。
- 真实媒体范围、容量、部署环境、S3 目标、授权残余窗口、RPO/RTO 和开源发行信息仍是分阶段输入，不得从本 ADR 推测数值。
- M0 可以编写设计合同和一次性风险验证，不创建业务页面、业务路由、正式数据库迁移、存储适配器或部署。
