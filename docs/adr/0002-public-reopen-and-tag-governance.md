# ADR 0002：公开重开与标签字典治理

- 日期：2026-11-16
- 状态：D01/D02 已明确确认并进入正式实现；主要本地链路已验证，完整验收状态见[首期部署与验收记录](../operations/deployment-validation.md)
- 关联：[详细设计索引](../design/README.md)、[权限与验收](../design/04-permissions-and-acceptance.md)

## D01：关闭后重新开启公开入口

关闭实例公开总开关时，保留 Publication 记录和快照，不逐项撤回、不删除素材，但立即拒绝新的公开查询、文件签发和预览资格。

管理员显式重新开启时，恢复仍 active 且素材/版本仍有效的既有公开快照。设置页面必须在操作前说明将恢复的范围和数量。以下内容不因此公开：从未公开、已撤回、已归档或不再满足有效条件的素材；内部最新元数据也不替换原公开快照。

公开授权 epoch 的变化使旧应用 grant/capability 失效。重新开启后可以为有效快照签发新 grant，不要求每个作者重新公开，也不能复活旧 grant。已签发的第三方对象存储 URL 仍存在有限 TTL 窗口，已取得的文件副本无法收回；具体 TTL 和运维参数另行冻结。

该决定减少总开关恢复后的重复操作，同时要求显式说明重新可见的影响。它不授予管理员公开他人素材或更新他人公开快照的能力。

## D02：标签字典治理

默认普通 member 只能给本人有权编辑的素材选择已有标签；上传无需填写或创建标签。

标签字典默认由系统管理员治理，也可由其将固定 `tags.manage` 能力授予可信自定义角色。首期字典操作只有创建、改名、停用和恢复；标签合并、层级标签与成员自由创建后的治理机制均不纳入首期。

停用保留已有素材关联与历史显示，禁止新增关联；改名、停用或恢复不能自动修改既有公开标签快照。公开时服务端从已关联标签读取名称并固化字符串快照，不向游客输出内部 tagId。

该决定通过明确治理权控制字典质量。业务能力可委派不等于系统管理权可委派：`system.*` 仍仅属于固定系统管理员角色，且标签治理不授予他人素材公开权。
