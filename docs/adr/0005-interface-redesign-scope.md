# ADR 0005：核心界面重构的范围与确认门槛

- 日期：2026-11-16
- 状态：已确认 B「创作工作台」、第一、二、三批范围、双栏详情与 code-first

## 决定

用户明确允许在保留核心业务能力的前提下替换旧视觉框架。因此 [ADR 0003](0003-prototype-visual-direction.md) 中“不再重选整套视觉方向”以及固定沿用 v0.2 视觉的限制已被本决定替代。v0.2 保留为历史与现状参考，当前运行样式不因此被立即修改。

本次在现有工程中进行产品界面重构，不新建仓库或工作树；目标是可运行的高保真前端，可以使用明确标记的高质量合成数据。没有后端重构、历史素材迁移、数据库改动或动效隔离降级。

先调查产品、源码与实际界面，提出首期页面范围、流程、组件与 2～3 个明显不同的视觉方向，等待用户明确确认后，才实施设计系统、基础组件与页面。按切片交付，不一次性开发全部页面。

本轮已补充确认：主要面向设计师、产品与内容创作者的日常协作；找灵感与找可用素材同等重要。后续采用 code-first，直接实现可运行前端，再做真实视觉与交互检查。

## 保留与待确认

所有权、公开快照、游客下载、归档恢复、标签治理、私有收藏和动效执行安全边界继续遵循现有决策。视觉探索不授权修改这些规则。

桌面双栏详情、深链独立页与手机全屏是现有交互合同；本轮建议保留。若选择改变容器的视觉方向，应在方向评审中明确，而非隐式替换。

已确认 B「创作工作台」，第一批包含基础组件、素材库、详情、上传和必要登录入口；保留桌面双栏详情，直接实现可运行前端并检查桌面和手机。2026-11-17 用户继续确认第二批集合整理和公开页面，沿用第一批设计规范与现有权限规则，同样检查桌面和手机；包含提案中的收藏、归档和标签治理。2026-11-17 用户继续授权第三批账号与管理页面，沿用既有设计规范和权限规则，完成后检查桌面与手机。分批范围见[界面重构评审](../design/07-interface-redesign-proposal.md)。本 ADR 不宣称新界面已实现、旧缺陷已修复或全量业务已验收。
