# ADR 0006：可选阿里云 OSS 存储

- 状态：用户已授权接入；实现与本地验证完成情况见验收记录，真实云目标待配置。
- 日期：2026-11-17。

## 决策

每个实例可以选择 Local 或原生阿里云 OSS，API 与 worker 共用存储合同。数据库记录后端与位置，不能用配置切换代替已有文件迁移。通用核心不绑定任何组织的 Bucket、域名或凭据。

OSS 使用专用私有 Bucket、V4 签名和服务端分片上传，禁止覆盖最终键。当前实现要求 Bucket 从未开启版本控制，以满足 OSS 的条件写入语义。GC 使用同键零字节 tombstone 防止迟到上传复活；不新增面向用户的永久删除能力。

文件授权继续经过拾灵 API，不将 OSS 直链或长期凭据交给浏览器。账号停用、权限变化、公开撤回和恢复代次继续按现有规则执行。品牌文件同样进入所选存储。HTML/ZIP 上传及动效执行继续关闭。

备份由停写期间的 PostgreSQL dump 与经过摘要校验的对象清单组成。恢复使用全新位置，重绑定台账前必须完成所有对象复核，并执行 ADR 0004 的恢复安全动作；管理员不能代替所有者重新公开。

## 边界

本地协议服务用于 SDK 与业务衔接测试，不能证明阿里云 RAM、TLS、网络、费用或容量已验收。不自动创建 Bucket、不接触旧系统、不推送代码或部署线上。现有本地 `v0.1.0-rc.1` 保持冻结，不代表已包含本次 OSS 增量。

具体环境变量、RAM、Docker 出网和恢复顺序见 [OSS 运维](../operations/oss-storage.md)；实测证据见 [OSS 验收](../operations/oss-validation.md)。
