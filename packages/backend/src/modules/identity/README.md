# 身份模块（identity）

职责：用户、登录身份、会话、邀请、密码恢复与角色。

`service.ts` 提供初始化、登录/退出、再次认证、改密、邀请接受/撤销/重签、恢复凭据、成员状态与角色治理。所有身份写操作使用数据库事务与串行治理锁，成功审计随业务提交；密码采用带随机盐的 scrypt，一次性 token 与 session 仅存摘要。

`authorization.ts` 每次从当前会话、账号、身份、角色与能力判断访问。成员禁用不修改素材所有权或公开记录；恢复密码不自动启用停用账号。系统管理员角色固定，自定义角色不能获得 system.*，所有角色均不存在代替他人公开的能力。
