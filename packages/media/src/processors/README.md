# 计划中的处理器边界

图片、MP4 视频和自包含 HTML/ZIP 动效分别承担格式验证、资源限制和派生产物职责；MP4 不替代网页动效。处理器未来需有精确版本、受控输入输出与必需/可选产物合同。

当前实现提供三类受控处理器：Sharp 图片解码与 WebP 预览、FFprobe/FFmpeg MP4 探测与播放版本、HTML/ZIP 离线结构校验与静态风险说明产物。所有处理器只接受本地输入/输出路径和显式资源预算，不持有数据库或长期云凭证，也不能自行改变素材或公开状态。

网页动效的 `executionReady` 固定为 `false`。ZIP 结构通过只表示离线检查未发现已知结构问题，并不代表其中脚本安全；在独立 Cookie 域、服务器网络隔离、云元数据阻断、资源限制和真实录制封面完成验收前，正式上传入口保持关闭，处理器生成的 SVG 说明图与 manifest 仅供风险验证，不执行上传脚本，也不能使素材进入 ready。
